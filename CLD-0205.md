# CLD-0205: Reported email: 'Bexley contract ready for signature'

Engagement: Cloudora · Shift 2 · 2026-08-26
Verdict: True positive · Severity (my rating): High (reported Medium)
QA review: Satisfactory

## Alert
marcus.oje@cloudora.io (finance) reported an email titled 'DocuSign: Bexley integration contract ready for signature', received 07:44 UTC from notifications@docusign-verify.example. Link in the email resolves to a credential entry page at 192.0.2.203.

## Hypothesis
Malicious: phishing email spoofing DocuSign and riding on the live Bexley integration project to get a finance contact to enter credentials. Benign: legitimate DocuSign notification tied to the actual Bexley integration work.

## Evidence checked
01_reported_bexley_contract.eml, Authentication-Results header: SPF fail, DKIM none, DMARC fail, all three checks failed; Sender domain docusign-verify.example, not docusign.com; Link target resolves to a bare IP, 192.0.2.203, not a DocuSign domain; Bexley integration project is live this week and was mentioned in morning handover, so the theming lines up with something real; Marcus did not enter credentials.

## Action
Recommended email admin quarantine the message and block sender domain docusign-verify.example and IP 192.0.2.203, since I can't do it myself. Asked them to check tenant-wide for other copies. Notified Bexley in case they were targeted too. Confirmed to Marcus it was malicious and thanked him for reporting it.

## Justification
 All three authentication checks failed, SPF, DKIM, and DMARC, so this isn't a real DocuSign message. Sender domain docusign-verify.example is close enough to docusign.com to fool someone at 7:44am, and the link goes to a bare IP instead of a real DocuSign domain. Bexley theming lines up with a project that's actually live this week, so whoever sent it had real context, not a lucky guess. Impact is High because it's aimed at finance during an active contract signing, but confidence is Possible since it's one report, no credentials entered, and the tenant search came back clean. High impact plus Possible confidence lands on S3 per the matrix.
