# CLD-0212: Watchlist IP activity: blocked attempts on daniel.reeve@cloudora.io

Engagement: Cloudora · Shift 3 · 2026-08-27
Verdict: False positive · Severity (my rating): Informational (reported High)
QA review: Good

## Alert
An alert fired when known-bad infrastructure from August's incident CLD-0001 repeatedly targeted daniel.reeve@cloudora.io with four sign-in attempts between 04:40 and 05:01 UTC. The standing Conditional Access block intercepted all four requests at the tenant boundary, denying access before any password checks occurred.

## Hypothesis
Malicious: The threat actor from incident CLD-0001 is recycling known attack infrastructure to run automated password-spray or credential-stuffing attempts against Cloudora users.
Benign: An authorized user connecting through a recycled, miscategorized, or overlapping network range matching a historic blocklist entry.

## Evidence checked
Morning handover confirms 198.51.100.212 is a tracked Lagos IOC from the August CLD-0001 password spray, with active tenant-wide Conditional Access blocks;
Sign-in logs in signin_week1.csv show four attempts between 04:40:55Z and 05:01:33Z
from Lagos, NG on an unknown device/browser;
All attempts show the result Blocked (CA policy) with zero credential or MFA evaluation, confirming no authentication handshake was permitted.

## Action
Closed referencing CLD-0001.

## Justification
While the traffic is malicious in intent, the threat was completely neutralized at the edge by the standing CLD-0001 Conditional Access policy. Because authentication processing was aborted before reaching password evaluation, no valid session was created, no data was exposed, and no further containment action is required
